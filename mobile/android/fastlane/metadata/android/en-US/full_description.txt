Pizcloud is a mobile client for a self-hosted server setup. To use the app fully, you need to deploy and manage your own server instance.

After setup, the app works as a direct photo and video backup solution from your phone.

<b>Features:</b>

* Upload and browse photos/videos.
* Multi-user support.
* Fast timeline navigation with drag scrollbar.
* Automatic backup.
* HEIC/HEIF backup support.
* EXIF extraction and display.
* Real-time updates from uploads across multiple devices.
* Image tagging/classification using the ImageNet dataset.
* Object detection powered by COCO SSD.
* Search by tags and EXIF fields (lens, make, model, orientation).
* Upload from local computer/server using CLI tools.
* Reverse geocoding from image EXIF metadata.
* Display asset locations on map (OpenStreetMap).
* Curated places on the search page.
* Curated objects on the search page.
